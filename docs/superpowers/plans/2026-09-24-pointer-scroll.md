# 自动滚动后的鼠标定位

**实测原因：** 连续输入会让本机页面自动向下滚动，编辑区也增高；但静止鼠标只保留输入前的相对坐标。接收端不跟随滚动，屏幕外的位置原本仍留有 DOM。两端同尺寸、对齐滚动位置后测得旧鼠标位置偏差约 54px。

**用户确认：** 指彩色鼠标指针；对方鼠标在接收端屏幕之外时不显示，不增加跟随滚动或方向提示。

1. 用真实连续输入复现位置偏差；增加接收端滚动进出指针位置的显示测试。
2. 记录最后一次本机鼠标视口坐标；布局、滚动或大小变化后重新定位。沿用 50ms 节流，对未变化的引用及归一化坐标去重，避免 Awareness 消息相互触发重发。
3. 离开、失焦、隐藏、断线时一起清除视口坐标，不能因后续测量恢复旧指针。仅在接收端视口内渲染标记；滚回对应区域后可重新显示。
4. 验证相关 E2E、类型检查及构建后提交推送，保留双端独立阅读位置。

验证记录：4 项新增回归与原有光标、鼠标、整段选择用例合计 41 项 E2E 通过；76 项前端单测、类型检查及生产构建通过。浏览器测试使用单机两个独立上下文连接真实 Python 服务，本轮未实测两台物理设备。
