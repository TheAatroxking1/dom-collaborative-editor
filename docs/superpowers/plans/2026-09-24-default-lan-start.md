# 默认打开局域网页面

**目标：** Windows `start.bat` / `serve.ps1` 和 macOS `serve.sh` 在服务成功监听后，默认用系统浏览器打开实际局域网地址。

**设计：** 两个平台共用一个小型 Python 启动入口 `backend/serve.py`，复用 `app.share.lan_ipv4_hosts`。一个地址直接打开，多个地址在终端选择；提供指定地址和不打开浏览器的参数。没有局域网候选时明确提示并回退到本机地址。显式绑定地址、端口和证书仍生效。使用 Uvicorn 原来的前台运行与信号处理，仅在成功 startup 后打开浏览器；端口占用或应用启动失败时不打开。

**范围：** 不改变现有页面地址，不迁移 IndexedDB，不新增依赖，不修改编辑或同步机制。开发模式仍按开发指南启动。

1. 为地址选择、启动后打开、启动失败、浏览器打开失败添加测试，先验证缺失行为。
2. 实现共享启动入口；两个系统的脚本保留现有依赖检查和数据目录语义，传入启动参数。
3. 更新 README、本地/局域网、macOS 和演示指南，使默认步骤指向终端显示并自动打开的局域网 URL；说明旧来源的未同步内容与 HTTP 离线刷新边界。
4. 执行后端测试、Windows PowerShell 5.1 / Git Bash 参数验证，以及实际服务就绪与浏览器打开验证。检查 Ctrl+C 正常停止、编码及差异后提交并推送。
