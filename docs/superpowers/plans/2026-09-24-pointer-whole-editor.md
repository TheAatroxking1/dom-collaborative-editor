# 整个正文输入区域显示协作者鼠标

**问题：** 当前 locatePointer 只接受真实段落矩形；输入区域底部、内边距和段间留白均被视为无位置。

**设计：** 段落内继续发送稳定段落引用和归一化坐标；区域内未命中段落时发送 paragraph:null、space:'surface' 和整个 editor-surface 的归一化坐标。接收端按对应段落或自身输入区域投影。外部坐标不发布，失效段落引用不退化到区域位置，继续沿用 Awareness、节流及离开/断线清理。不新增依赖或修改正文数据。

1. 在真实双浏览器测试中复现空文档、底部空白、内边距/段间留白不显示。
2. 最小修改 paragraphs.ts 定位/投影和 presence.ts 校验/发布/渲染；区域定位不依赖段落快照已就绪。
3. 验证空白区域、不同尺寸与接收端滚动/缩放、拖动捕获移出边界、原有文字协作及断线场景。
4. 更新行为说明，运行类型检查、构建和相关回归后提交推送。两端更新页面后均支持新增的空白位置。
