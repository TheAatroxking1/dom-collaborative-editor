# 协作光标、鼠标指针与段落框选设计

状态：用户已确认扩展范围和拖动交互；供 Claude 实施。本文没有宣称功能已经完成。

## 目标与现状

在现有 DOM 编辑器上增加可见的协作状态，以及整段选择、复制和删除。保留两人同段输入、断线编辑、本地恢复和协作 Undo/Redo。

实际应用目录：`F:\基于DOM的协作编辑器\.claude\worktrees\confident-mclaren-506b7a`。2026-09-24 核对提交为 `6df4770`；执行前重新核对，保留 Claude 后续修改。外层目录只有规划资料，不在外层重新创建应用。

现有实现：Vue 3、Tiptap 3.31.3、Yjs 13.6.32、y-websocket 3.1.0、y-indexeddb 9.0.12、FastAPI/pycrdt。正文是 `body` 下的 Paragraph/Text/HardBreak；标准同步和协作撤销已存在。Python YRoom 已处理 Awareness 消息。

## 本轮范围

| 能力 | 用户看到的行为 | 实现边界 |
| --- | --- | --- |
| 协作者文字光标 | 看到对方正在输入的位置、访客名称与颜色 | 用 CollaborationCaret |
| 协作者文字选区 | 看到对方选中的几个字或跨段文字 | 同一扩展处理，不自研字符位置同步 |
| 协作者鼠标指针 | 看到对方鼠标所在段落的大致位置 | 段落引用 + 段内归一化坐标 |
| 整段框选 | 从正文左侧留白拖动，选中矩形触及的段落 | 无模式按钮，不改变正文内拖动选字 |
| 协作者段落选区 | 在本机对应段落显示对方选中状态 | 共享段落引用，不共享框选矩形像素 |
| 批量复制、删除 | 按文档顺序复制；一次删除当前选中段落 | 复用纯文本复制与现有协作历史 |

不增加账号、登录、昵称设置页、在线成员面板、拖拽排序、富文本、评论、段落锁、文档锁、跨设备剪贴板或新的历史系统。自动生成访客名和固定调色板颜色即可。没有后台任务或新增存储服务。

## 已确认的操作规则

1. 正文内按下并拖动：保持原有文字选择，包含跨段选择。
2. 在段落左侧约 24px 留白中按下鼠标主键，移动超过 4px 后开始矩形框选；不要求先点按钮。留白不覆盖文字。
3. 以矩形与段落完整矩形相交为命中。命中区域包含该段左侧留白，因此纯竖向拖动也能选段；空段同样可以选中。
4. 拖动中显示矩形和段落高亮；松手后矩形消失，高亮与“已选 N 段”保留。
5. 点击选区外清除；点击正文先清除整段选区，然后让原本的文字定位/拖动正常执行。选中段落左侧的简单点击可保留选区；空白处简单点击清除。
6. 点击“复制所选段落”“删除所选段落”先执行操作。工具栏和手动复制文本框属于操作区域，不得在捕获阶段提前清空选区。
7. 复制后保留选区，删除后清除。Escape 可清除；没有多选追加、Ctrl 点选或模式开关。
8. 框选完成后聚焦可键盘操作的编辑器外壳。所选段落存在时支持 Ctrl/Cmd+C、Delete/Backspace、Escape；Ctrl/Cmd+Z 等继续调用既有协作撤销。不得拦截昵称以外的输入框、备份区、手动复制框的快捷键。
9. 中文输入法组合输入期间不开始框选或批量删除。鼠标增强不接管 touch 事件；触屏保留原有文本编辑，本轮不增加触屏整段框选。
10. 支持普通页面滚动及窗口调整后的重定位；本轮不增加拖到边缘自动滚屏。

## 数据与定位

### 持久内容和临时状态

正文仍只由现有 Y.Doc、IndexedDB 与服务端 store 保存。访客信息、文字光标、鼠标和段落选区只放在同一个 WebsocketProvider 的 Awareness 中，不进入正文、备份或撤销栈。

`DocumentSession` 暴露现有 `provider: WebsocketProvider`。组件使用该对象的 Awareness，不创建第二个 Provider/Awareness，不绕过先恢复缓存再连接的顺序。关闭会话前置本地 Awareness 为 null，随后按原生命周期销毁。

| Awareness 字段 | 所有者与内容 |
| --- | --- |
| `user` | CollaborationCaret；自动访客名、`#RRGGBB` 颜色 |
| `cursor` | CollaborationCaret；不手工写入或解释其内部格式 |
| `pointer` | 本项目；`{ paragraph, x, y }` 或 null，x/y 在 [0,1] |
| `paragraphSelection` | 本项目；段落引用数组，清除时 `[]` |

更新自定义字段用 `setLocalStateField`，不覆盖其他字段。在线信息以 Awareness 为准；弱网中离线识别可能延迟，不显示“立即知道对方离线”之类承诺。

### 稳定段落引用

不增加持久 Block ID，不迁移旧文档，不保存段落下标作为身份。对已集成的 `Y.XmlElement('paragraph')`，在其末尾创建 Y.RelativePosition，将 JSON 中的 type ID 作为该段落引用。解析时要求绝对位置的 type 仍是当前 `body` 的顶层 paragraph。

当前时刻可按 Y 根节点和 ProseMirror 顶层节点的对应顺序取得位置与 DOM；这种临时遍历下标不能存进选区。测量只在编辑器事务完成后进行。组合输入中或两种视图尚不一致时跳过本帧、禁用批量动作，不能猜位置。

| 变化 | 选区规则 |
| --- | --- |
| 前面或中间插入新段落 | 原有选中段落继续选中，新段不自动加入 |
| 修改选中段落内容 | 保持选中；复制/删除取执行时当前内容 |
| 远程删除选中段落 | 移除失效引用；不会选到顶替其下标的段落 |
| 分段 | 只跟随库保留的原 Y 段落引用，新产生的段落不自动选中 |
| 合段 | 消失的引用移除；存活段落若原本被选中，则高亮合并后的整段 |
| 所有引用失效 | 清空选区并隐藏批量按钮 |
| 撤销删除 | 恢复正文；不自动恢复已经清除的段落选区 |

分段/合段不承诺固定保留“上半段”或“左侧段”，其身份由绑定库决定。实际高亮必须始终反映下一次操作的范围。选择不加锁，也不保存选择时的正文快照。

### 指针与绘制

原始 clientX/clientY 只用于本机命中测试。发送鼠标所在段落引用与在该段 DOM 矩形中的归一化 x/y。接收端先找到同一个段落，再按本机尺寸还原位置。这是“对应段落内的大致鼠标位置”；不同换行下不能解释为同一个字符，精确字符位置由文字光标负责。

指针只在正文段落内共享；段间空白、工具栏或正文外隐藏。移动最多每 50ms 发布一次，保留最后一次位置；退出、失焦、页面隐藏、断网时立即取消待发消息并置 null，防止延迟回调把旧指针重新发出。静止指针可保持显示直到上述事件，避免另造定时心跳。

指针和段落高亮均用正文外的 DOM overlay，`pointer-events: none`、`aria-hidden="true"`。以同一个非滚动 overlay 容器为坐标原点；正文事务、Awareness 变化、scroll、resize 触发 requestAnimationFrame 合并重算，不能每帧永久轮询。远端矩形不复刻，只画命中段落。选择状态不创建 ProseMirror 文档事务。

使用 textContent/Vue 插值显示名称，颜色只接受十六进制格式，远端坐标要求有限且在 [0,1]，解析失败的引用忽略。尚未收到对应正文时暂不画，正文更新后重试。断网隐藏全部远端覆盖层，保留本地选区与离线编辑；重连共享当前选区，鼠标等待新的移动事件。

光标昵称是编辑器装饰 DOM，不是正文。正文复制继续使用编辑器模型序列化；测试提取文本也必须排除光标装饰，不能直接把段落 innerText 中的访客名当成同步内容。

## 批量操作与撤销

复制按照执行时的文档顺序获取段落纯文本，段间一个 `\n`，HardBreak 保留为换行，保留空段。按钮复用 `tryCopyText` 和现有手动复制降级。对原生 Ctrl/Cmd+C 的 copy 事件，可以同步填入 `clipboardData`；不要全局抢占剪贴板事件。

删除先同步重新解析所有引用，再从后往前删除 ProseMirror 范围，一次 dispatch 完成。删空全文时在同一事务中留下一个空段落。通过现有 `yUndoPluginKey` 取得 UndoManager，在批量删除前后 `stopCapturing()`，避免和前后输入粘成一次撤销；不创建第二个历史管理器。

一个 undo 恢复该批次，一个 redo 重新执行；不会撤销其他客户端独立的编辑。不得还原整篇 JSON 快照来模拟撤销。两端断网后，一端删整段而另一端编辑此段时，由现有 Yjs 树删除语义处理，不能额外承诺被删段中的并发输入始终可见，也不暗中增加锁。
