## 历史设计与实施过程

`superpowers/specs/`、`superpowers/plans/` 和 `*-claude-handoff.md` 保留开发过程，便于了解取舍；它们不是当前版本的启动说明。

- 2026-09-21：首版自研协议方案，已被替代。
- 2026-09-23：FastAPI 与现成协作库方案，随后增加离线页面缓存、局域网运行和备份迁移。
- 2026-09-24：协作文字光标、鼠标、段落选择与批量操作。

历史文档中的本机绝对路径、工作树名称、基线提交和“外层 main 只有文档”描述只适用于当时的开发环境。**从 GitHub 克隆后，仓库根目录就是包含 frontend / backend 的应用目录**；请从项目 README 开始。

当前行为以最新源码、测试和 README 为准。自动化测试可通过根目录的 `scripts/verify.ps1` 重新执行；不要把旧验收记录里的数量当作最新测试结果。
