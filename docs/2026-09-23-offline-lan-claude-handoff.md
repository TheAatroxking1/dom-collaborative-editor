## 保持简单的约束

- 不新增账号、云服务、Node 后端、Redis、消息队列或自研 ACK/重试协议。
- 不增加 PWA 安装入口、文档管理列表、版本历史或“立即刷新更新”。
- 不改 schema、body 根、缓存前缀，不为测试清除用户数据。
- 不把页面缓存完成、连接成功或 CRDT 同步成功写成服务器已保存。
- 备份合并需当前服务端在线校验原 UUID；离线仍能导出和预览。404 保留预览供手动复制，不自动建新文档。
- HTTP LAN 仍支持在线协作，但 SW 完整离线刷新要求可信 HTTPS；不能靠忽略证书/浏览器安全选项绕过验收。
- 不执行 GitHub 推送，不自动安装证书信任或修改防火墙。
